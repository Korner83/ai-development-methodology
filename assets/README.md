# Static diagrams

The README uses workflow-overview.svg and planning-cascade.svg so the same diagrams display on GitHub and the existing GitHub Pages site without client-side rendering.

The corresponding .mmd files preserve the original Mermaid source. The SVGs are separately laid out static summaries of that source; they are not automatically regenerated by the site. If the concepts change, review the source and image together.

The SVGs contain no script, embedded HTML, external resource references, or custom font downloads. Each supplies a title and description; the README also gives image alt text.
